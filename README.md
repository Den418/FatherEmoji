# Эмодзи-бот

Бот для создания кастомных эмодзи-паков в Telegram (hydrogram).

## Запуск

```
pip install -r requirements.txt
python main.py
```

Токены лежат в `config.py`; их можно перекрыть переменными окружения
`API_ID`, `API_HASH`, `BOT_TOKEN`, `DB_PATH`, не трогая код.

База `bot_users.db` и файл сессии `emoji_pro_bot.session` подхватываются
из папки запуска — старая база от `main2.py` подходит без миграций.

## Структура

| Файл | За что отвечает |
|---|---|
| `main.py` | запуск бота |
| `config.py` | токены и настройки |
| `texts.py` | **все тексты и подписи кнопок** — интерфейс правится только здесь |
| `keyboards.py` | клавиатуры (лейблы берёт из `texts.py`) |
| `db.py` | sqlite: пользователи, админы, каналы, паки |
| `tg.py` | клиент hydrogram + прямые вызовы Bot API, проверка подписок |
| `media.py` | обработка файлов: webp 100×100, webm ≤245 КБ, векторизация растр → .tgs |
| `packs.py` | операции с паками: добавление, копирование, передача, обложка |
| `handlers/commands.py` | /start, /help, /admin, /cancel, /done + перехватчик рассылки |
| `handlers/user.py` | меню, FSM создания, текст/стикеры/медиа |
| `handlers/callbacks.py` | инлайн-кнопки (выбор пака, редактирование, подписка) |
| `handlers/admin.py` | админ-панель, рассылка, выгрузка ID |

В `texts.py` подстановки вида `{link}`, `{title}`, `{count}` заполняет код —
при редактировании их нужно оставлять на месте.

## Меню

Главное меню: «✨ Создать пак», «✏️ Редактировать», «👨‍💻 Канал», «ℹ️ Помощь».
Добавление и удаление эмодзи живут внутри «Редактировать»: после выбора пака
открывается меню — добавить эмодзи, удалить эмодзи, переименовать, обложка,
передать, удалить пак целиком.

## Векторизация

Переключалка из трёх режимов появляется последним шагом при создании пака
и под сообщением во время наполнения (кнопки остаются в чате — режим можно
менять когда угодно):

- «🚫 Без векторизации» — картинки добавляются статичными webp 100×100;
- «⚡ Векторизовать всё» — каждая картинка автоматически превращается
  в векторный .tgs 512×512 (растр → SVG → Lottie → gzip);
- «❓ Спрашивать каждую картинку» — перед каждой картинкой бот спрашивает:
  вектором или обычной.

Последний выбор запоминается и предлагается в следующем паке. Качество —
лестницей: сначала максимальная детализация, при превышении лимита .tgs
в 64 КБ параметры упрощаются, пока файл не влезет.

Telegram запрещает смешивать форматы: в пак со статикой вектор не добавится,
а в векторном режиме видео и гифки не принимаются.

Зависимости `vtracer` и `lottie` необязательны: без них бот работает,
а векторный режим честно об этом скажет.

## Форматы эмодзи

| Режим | Формат | Лимит | Размер |
|---|---|---|---|
| Картинка без векторизации | webp, static | — | 100×100 |
| Видео/гиф | webm VP9, video | 245 КБ | 100×100 |
| Векторизация | tgs, animated | 64 КБ | 512×512 |
